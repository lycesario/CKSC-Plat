知识库中台（企业全域统一知识库 / Knowledge Base 中台），是企业全域结构化、半结构化、非结构化、图谱化知识统一采集、标准化治理、分层存储、混合检索、知识图谱推理、全生命周期运营、多租户隔离、MCP 标准化输出的企业核心知识资产底座，属于 AI 体系前置知识供给层基础中台。

战略定位：企业全域多模态知识统一资产沉淀中心、三路混合检索调度中枢、KBGraph 知识图谱推理平台、知识全生命周期运营中心、多租户知识隔离管控底座、全 AI 链路标准化知识供给中枢、企业数字经验沉淀载体。

层级边界：底层依赖层（算力中台向量 / 图计算弹性算力、向量库中台、IaaS/PaaS 分布式存储、数据中台业务数据源、图数据库、对象存储）；核心能力层（专注多源知识采集、文档解析、分层存储、混合检索、KBGraph 图谱、知识治理、权限计量）；上层赋能层（统一通过 MCP Resource 对外输出检索能力，供给 RAG、Prompt、Agent、场景等所有上层 AI 中台）。

全域上下游标准分层链路：算力 / 向量 / 数据 / IaaS → 知识库中台 → MCP 中台 → RAG 中台 → Prompt 中台 → Token 中台 → Skill 中台 → Agent 中台 → MaaS → 场景中台

知识库中台 · 核心价值总结

统一全域企业知识资产底座，终结部门零散文档、项目独立小库，实现全格式知识统一纳管、资产复用；
三路混合检索 + KBGraph 多跳图谱双引擎，兼顾精准术语、语义匹配、复杂关联推理，问答准确率提升 30% 以上；
三层分层知识全生命周期闭环，文档版本、时效、归档标准化管控，杜绝过期政策误导业务；
每条结果绑定原始文档溯源 + 双层事实校验，财务 / 政务 / 风控等高合规场景满足监管，强力抑制大模型幻觉；
KBGraph 沉淀企业业务实体关系经验，自动识别检索缺陷、推送知识库优化方案，实现知识自治迭代；
标准化 MCP 输出，无缝对接 RAG/Prompt/Agent 全 AI 链路，是所有大模型应用统一私有可信知识供给层；
多租户细粒度隔离、全链路审计，兼顾业务独立性与数据安全合规，支撑企业全域 AI 可信智能化长效落地。
