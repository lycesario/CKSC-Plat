数据中台完整定义

通用总述
1.1 标准官方定义
数据中台（Data Middle Platform）是企业级全域数据资产化与服务化基础设施，依托统一标准、统一集成、统一存储、统一治理、统一服务五层闭环能力，打通企业内外部异构数据孤岛，将原始业务数据标准化加工为可复用、可计量、可共享的数据资产（主数据、指标、标签、模型、知识库），并以标准化 API、报表、查询、AI 服务等形式，面向业务前台、业务中台、决策系统持续输出数据价值，实现一次建设、全域复用、数据驱动业务的数字化核心中枢。
1.2 核心本质与定位
  • 战略定位：数字化转型底层数据底座，解决 “数据不通、口径不一、重复取数、数据不可信、价值难释放” 五大痛点；
  • 核心本质：把数据变成可服务的资产，区别于传统数据仓库（仅做存储统计）、数据湖（仅做原始存储）；
  • 核心特征：全域统一、资产化、服务化、治理贯穿、云原生弹性、批流一体、全链路可追溯；
  • 边界区分
    • 数据仓库：仅结构化离线统计，无统一治理、无对外服务能力；
    • 数据湖：存储全类型原始数据，缺乏标准化建模与指标体系；
    • 数据中台：湖仓一体底座 + 全域治理 + 资产中心 + 统一数据服务完整闭环。
1.3 建设核心目标
  1. 消除数据孤岛，全域数据统一汇聚、统一标准；
  2. 建立可信数据资产体系，实现数据可管、可控、可查、可用；
  3. 沉淀通用数据能力，业务需求自助取数，减少重复开发；
  4. 支撑实时经营、精细运营、智能风控、AI 训练、监管报送全场景；
  5. 满足等保、隐私合规、行业监管的数据安全要求；
  6. 量化数据资产价值，实现数据对内赋能、对外合规共享。

3.3 数据架构（全域数据分层流转 + 模型体系，OneData 标准）
采用湖仓一体五层分层架构，所有数据统一流转、统一标准、统一血缘追踪：
ODS
原始数据层：存储数据湖，全量原样同步源系统数据，不做清洗；源库全表快照、实时 CDC 日志、原始埋点、IoT 原始数据；数据原始备份，问题溯源，保留最细粒度原始明细；Parquet/ORC，冷热分层归档
DWD
明细数据层：基于 ODS 完成清洗、去重、脱敏、格式统一、脏数据隔离；按业务过程构建明细事实表，保留最细业务粒度；统一字段标准、统一编码、统一主数据映射
DWM
中间层：按维度轻度聚合，消除重复关联，减少重复计算；宽表模型，用户宽表、订单宽表、商品宽表；多指标复用的中间计算结果，支撑上层汇总
DWS
汇总层：按业务主题 + 固定维度聚合，形成汇总宽表；日 / 周 / 月维度汇总表，承载企业核心原子指标、派生指标；OLAP 引擎，支撑高并发报表查询
ADS
应用集市层：面向单一业务场景定制加工，高度聚合；经营报表、大屏指标、风控模型特征、营销标签；各业务应用数据集市相互隔离，按需开放权限

3.4 技术架构（云原生、存算分离、批流一体）
整体分为 7 大技术分层，横向贯穿统一治理、统一安全、统一运维三大支撑体系：

分层 1：数据接入层技术栈

  • 离线批量：DataX、Sqoop、Flink Batch；实时 CDC：Flink CDC、Canal、Debezium；日志采集：Filebeat、Flume；API 接入：HTTP/HTTPS 网关、第三方数据同步组件；缓冲队列：Kafka、Pulsar（流数据统一缓冲）

分层 2：存储层技术栈

  • 数据湖存储：HDFS、对象存储 OSS/S3；数据仓库：Hive、Spark SQL；OLAP 交互式引擎：ClickHouse、Doris、StarRocks；实时存储：Redis、Tair、HBase；冷热分层：归档存储、低成本冷存，自动生命周期迁移

分层 3：计算引擎层

  • 离线批计算：Apache Spark、Yarn 资源调度；实时流计算：Apache Flink（流批一体统一引擎）；AI 计算：TensorFlow、PySpark ML、XGBoost；调度引擎：Airflow、DolphinScheduler、自研分布式调度

分层 4：数据开发层技术栈

  • 统一开发 IDE：Web 端 SQL 编辑器、Flink SQL 开发、Python 脚本；版本管理：Git、代码分支、发布流水线；数据沙箱：隔离测试环境，数据仿真、脱敏测试

分层 5：数据治理引擎层

  • 元数据：Apache Atlas、自研元数据采集服务；质量引擎：Great Expectations、自定义规则引擎；主数据引擎：主数据匹配、去重、黄金记录生成；标准引擎：字典统一映射、编码转换组件

分层 6：数据服务网关层

  • API 网关：Spring Cloud Gateway、Nacos 注册中心；服务组件：指标查询服务、批量导出服务、标签 RPC 服务；流量管控：限流、熔断、负载均衡、鉴权

分层 7：运维监控底座

  • 容器底座：K8s 云原生部署；监控告警：Prometheus、Grafana、告警推送；日志中心：ELK 全链路日志采集；资源计量：存储 / CPU 内存算力成本统计
