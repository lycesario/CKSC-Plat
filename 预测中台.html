预测中台（Prediction 中台 / 全域智能预测决策中台），是企业全域时序、因果、事件、多模态数据统一特征加工、混合预测模型流水线、预测任务调度、归因解释、PredGraph 预测知识图谱、预测效果自动化评测、业务决策输出、多租户隔离、自治迭代的智能预判与前置决策核心中台。

1.1 权威标准定义

向下对接数据预处理、数据湖仓、算力、训练、评估、向量、知识库中台；向上统一输出销量、客流、风险、设备故障、现金流、用户流失、库存、产能等标准化预测结果、归因报告、最优决策方案供给营销、风控、供应链、财务、运维、场景中台与业务 SaaS。

遵循「四层预测资产、时序 + 因果 + 事件混合建模、可视化预测流水线、PredGraph 预测知识图谱、可解释归因、离线批量 + 实时流式双预测、A/B 对照评测、自治调参迭代」八大核心建设理念。

核心解决行业痛点：各业务独立手写预测脚本、时序 / 因果模型分散无统一平台、特征重复开发、预测结果无统一口径、无法自动归因、预测精度无法量化、无行业模板、故障无法溯源、人工反复调参成本高、预测无法联动业务自动决策。

实现企业预测能力从 "业务零散 Excel、单机脚本" 升级为标准化预测资产、混合建模流水线、图谱驱动智能调参、全链路归因、自动化评测、自治迭代的全域前置决策底座。

1.2 预测中台核心定位与层级边界

战略定位：企业全域业务统一预测生产中心、时序因果混合建模调度中枢、预测归因解释平台、PredGraph 预测知识推理引擎、预测效果自动化评测中心、业务前置决策输出底座、预测模型自治迭代运营中枢。

层级边界：

底层依赖层：算力中台时序 / 图推理算力、数据预处理中台、数据湖仓、训练中台、评估中台、向量库、知识库、PaaS 云集群；

核心能力层：专注特征工程、混合预测建模、预测任务调度、归因解释、PredGraph 图谱、预测评测、决策输出，不承载原始数据存储、底层大模型推理；

上层赋能层：标准化预测指标、归因分析、最优行动方案输出至各业务中台与前端业务系统。

全域上下游标准分层链路：数据预处理 / 数据湖仓 → 预测中台 → 营销 / 风控 / 供应链 / 财务 / 运维 / 场景中台

预测中台知识体系是企业特征工程、时序因果建模、预测流水线、归因解释、图谱推理、行业落地、评测复盘、前沿演进的标准化、结构化、可推理、可复用、自进化专业知识合集。

预测中台专属知识图谱（PredGraph 预测知识图谱）体系

核心实体 · 关联 · 智能能力

PredGraph 预测知识图谱，是企业业务场景、特征、预测模型、事件扰动、预测误差、归因、优化策略、租户的时序因果智能关联网络，解决预测依赖人工调参、误差无法定位、场景无成熟模板、调优经验流失痛点，实现业务场景自动推荐预测方案、高误差一键分层根因溯源、特征 / 模型优化智能推荐、预测经验自治沉淀。

3.1 PredGraph 核心实体体系

  • 业务场景实体：零售销量、设备故障、现金流、客流、流失
  • 特征实体：时序周期特征、因果干预特征、事件扰动特征
  • 模型实体：Prophet、TFT、因果森林、Time-LLM
  • 事件实体：促销、节假日、政策、设备停机、竞品活动
  • 预测任务实体：日度离线批量、实时滚动、中长期预测
  • 误差实体：高 MAPE、趋势偏差、事件冲击偏差、数据缺失
  • 归因实体：趋势贡献、周期贡献、事件扰动贡献
  • 优化策略实体：新增特征、更换模型、调整事件权重
  • 租户实体：企业、部门、业务项目
  • 资产实体：行业预测流水线模板、标准特征包

3.2 PredGraph 核心关联关系

  • 场景 ↔ 特征：销量场景适配节假日、促销事件特征
  • 场景 ↔ 模型：短期预测 Prophet、中长期 TFT
  • 任务 ↔ 事件：大促事件会显著提升预测误差
  • 误差 ↔ 诱因：高 MAPE 多因缺失事件特征
  • 误差 ↔ 优化：缺失事件→新增事件特征工程
  • 特征 ↔ 归因：促销特征贡献度占比量化关联
  • 租户 ↔ 预测资产：部门私有预测任务隔离
  • 每日预测误差、归因日志自动抽取三元组增量更新图谱
  • 模型 ↔ 指标：TFT 中长期 wMAPE 优于基础时序模型
  • 场景 ↔ 流水线：供应链专属库存预测流程模板

智能能力
