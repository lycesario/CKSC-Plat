策略中台（Policy 中台 / 统一决策中台），是企业全域业务规则、风控策略、营销决策、合规政策、审批流程、AI 判定逻辑统一资产沉淀、可视化编排、实时分布式决策、PolicyGraph 策略知识图谱、全链路效果评测、多租户隔离、数据驱动自治迭代的企业统一决策核心中台。

核心定位：企业全域规则 / 政策 / 决策统一资产沉淀中心、可视化决策编排中枢、分布式实时决策引擎、PolicyGraph 策略知识推理平台、策略 A/B 自动化评测中心、多租户业务隔离管控底座、决策效果自治迭代运营中枢。

层级边界：底层依赖层（算力中台、向量库、知识库、RAG、Prompt、Token、Skill、Agent、MaaS、数据中台、MCP、PaaS 云原生集群）；核心能力层（专注策略分层资产管理、决策流可视化编排、混合推理、PolicyGraph 图谱、A/B 评测、权限计量）；上层赋能层（统一输出标准化决策 MCP 服务，供给所有业务系统、数字员工、行业 Copilot）。

全域上下游标准分层链路：算力 / 向量 / 知识库 → MCP → 策略中台 → 场景中台 → 业务 SaaS / 数字员工

策略中台 · 核心价值总结

统一企业全域规则、政策、决策资产底座，消除各业务线硬编码决策烟囱，行业策略跨部门复用，开发人力成本降低 70% 以上；
可视化零代码编排，业务人员自主搭建判定流程，无需开发介入；
规则 + 模型 + 政策图谱三重混合推理，兼顾刚性约束、AI 预测、合规多跳关联，决策精准度大幅提升；
PolicyGraph 沉淀企业决策经验，自动推荐最优策略、定位误判根因，实现策略自治调优；
全自动 A/B 灰度实验，新策略可控放量，劣化一键回退，线上风险可控；
全链路决策可追溯审计，每条判定记录完整留痕，满足金融、政务强监管合规要求；
标准化 MCP 输出无缝对接 RAG/Agent/ 场景全 AI 链路，是企业所有业务智能化判定统一底层决策中枢。
