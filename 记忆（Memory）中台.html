记忆中台（Memory 中台 / 全域分层记忆统一管控底座），是面向大模型、智能体、Copilot、RAG、具身机器人，统一实现感官瞬时记忆、短期工作记忆、长期语义记忆、程序流程记忆、多模态记忆的全生命周期提取、压缩、分层存储、混合检索、MemoryGraph 记忆知识图谱、冲突消解、遗忘机制、多租户隔离、Token 优化、自治迭代的企业级统一记忆基础设施中台。

1.1 权威标准定义

向下对接算力、Embedding、向量库、图数据库、数据预处理、知识库、MCP；向上统一为 RAG、Agent、Copilot、具身智能、MaaS 提供标准化记忆读写、检索、上下文注入能力。

遵循「五层分层记忆资产、向量 + 图谱双混合检索、自动记忆蒸馏压缩、时序遗忘冲突消解、MemoryGraph 记忆图谱、多维度记忆评测、Token 成本自治优化、多租户数据隔离」八大核心建设理念。

核心解决行业痛点：各 AI 应用独立维护会话记忆，上下文无限膨胀、Token 消耗极高；长短记忆无分层管理，跨会话无法复用历史经验；记忆事实冲突、过期信息无法自动淘汰；记忆抽取、压缩逻辑重复开发；无统一记忆质量评测；用户 / 项目记忆隔离缺失；记忆关联经验无法沉淀；复杂多跳业务无法串联历史交互信息。

实现 AI 记忆管理从 "单会话临时缓存、全量上下文拼接" 升级为五层标准化记忆资产、图谱驱动关联检索、自动蒸馏降本、冲突自治、全链路可管控的统一认知记忆底座。

1.2 记忆中台核心定位与层级边界

战略定位：企业全域分层记忆统一生产存储中心、记忆提取压缩调度中枢、向量 + 图谱混合检索平台、MemoryGraph 记忆知识推理引擎、记忆质量评测中心、Token 成本运营中枢、AI 认知自治迭代底座。

层级边界：

底层依赖层：算力中台、Embedding 中台、向量库、图数据库、数据预处理、知识库、MCP、对象存储、时序库；

核心能力层：专注记忆抽取、分层存储、蒸馏压缩、混合检索、冲突遗忘、记忆图谱、质量评测、算力 Token 计量，不承载大模型生成、业务流程执行；

上层赋能层：标准化 MCP 记忆读写服务供给 RAG/Agent/Copilot/ 具身智能 / MaaS。

全域上下游标准分层链路：算力 / Embedding / 向量库 → 记忆中台 → MCP → Copilot/Agent/RAG/ 具身智能中台

记忆中台专属知识图谱（MemoryGraph）体系

核心实体 · 关联 · 智能能力

MemoryGraph 记忆知识图谱，是用户、会话、任务、事实、事件、工具、记忆故障、优化策略的时序因果智能关联网络，解决记忆零散、历史关联无法检索、冲突过期难发现、抽取压缩依赖人工经验痛点，实现用户提问自动召回多跳相关历史、记忆劣化一键溯源、压缩优化智能推荐、交互经验自治沉淀。

3.1 MemoryGraph 核心实体体系

  • 用户实体：企业员工、客户、项目账号
  • 会话实体：单次对话 / 任务交互会话
  • 记忆单元实体：短期片段、长期事实、程序流程、多模态记录
  • 任务实体：代码编写、报销、客户咨询、机器人操作
  • 事件实体：大促、项目变更、设备故障、政策更新
  • 故障实体：记忆冲突、过期失效、召回缺失、Token 过高
  • 优化策略实体：深度蒸馏、扩充抽取维度、调遗忘权重
  • 租户实体：企业 / 部门 / 项目
  • 指标实体：召回率、冲突率、Token 压缩降幅
  • 资产实体：行业记忆抽取压缩模板

3.2 MemoryGraph 核心关联关系

  • 用户 ↔ 会话：用户产生多条交互会话
  • 会话 ↔ 记忆单元：会话抽取生成长短记忆
  • 记忆 ↔ 任务：记忆绑定对应业务任务
  • 记忆 ↔ 事件：事件触发新增 / 更新事实记忆
  • 故障 ↔ 诱因：冲突多因新旧时序事实矛盾
  • 故障 ↔ 优化：Token 过高→提升蒸馏压缩力度
  • 租户 ↔ 记忆：租户记忆数据物理隔离
  • 时序有向边：记录事件发生先后、记忆更新时间
  • 每日交互日志自动抽取三元组增量更新图谱权重
  • 任务 ↔ 记忆模板：财务任务专属抽取规则

3.3 MemoryGraph 八大核心智能能力

智能能力

  • 用户交互、记忆抽取压缩经验自动结构化入库
  • 用户自然提问自动多跳串联关联历史记忆

智能能力

  • 记忆冲突、过期、召回不足一键分层根因溯源
  • 自动推送蒸馏压缩、抽取维度优化方案

智能能力

  • 同行业记忆配置模板智能复用推荐
  • A/B 记忆实验数据自动校准图谱关联权重

智能能力

  • 过期 / 冲突记忆批量自动识别预警
  • 记忆运维新人快速检索同类场景落地案例
