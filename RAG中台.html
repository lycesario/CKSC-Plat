RAG 中台（检索增强生成中台 / 全域知识资产中台），是企业全域结构化、半结构化、非结构化多模态知识统一治理、向量化存储、混合检索、知识图谱推理、上下文增强、生成校验、全生命周期运营的核心 AI 底层知识中台，属于 AI 原生基础支撑型中台。

战略定位：企业全域多模态知识统一资产沉淀中心、混合检索调度中枢、GraphRAG 多跳推理平台、检索增强上下文供给引擎、RAG 知识图谱推理平台、知识全生命周期运营中心、AI 幻觉防控核心底座、多租户知识隔离管控平台。

层级边界：底层依赖层（IaaS 硬件、算力中台向量 / 图计算弹性算力、PaaS 云原生集群、数据中台业务数据源、向量数据库、图数据库、对象存储）；核心能力层（专注知识摄入、分块向量化、混合检索、Graph 多跳推理、事实校验、知识版本、安全权限、评测运营）；上层赋能层（统一为 Prompt 中台提供可信上下文素材，供给 Token、Skill、Agent、MaaS、各类行业 AI 应用、SaaS 内置 Copilot）。

全域上下游固定分层链路：IaaS / 算力 / PaaS / 数据中台 → RAG 中台 → Prompt 中台 → Token 中台 → Skill 中台 → Agent 中台 → MaaS 大模型

RAG 中台 · 核心价值总结

统一全域企业知识资产底座，终结各业务线零散独立知识库，实现文档、数据库、多媒体知识统一纳管、资产复用；
三路混合检索 + Graph 多跳推理，解决传统单向量检索无法处理复杂关联业务问题，问答准确率提升 30% 以上；
双层事实校验全链路溯源，强力抑制大模型幻觉，输出答案全部绑定原始文档来源，满足财务、政务、风控等强合规场景；
三层知识分层 + 多租户细粒度隔离，兼顾公共知识与部门私有涉密文档，安全合规可审计；
RAGGraph 知识图谱沉淀企业业务实体关系经验，自动优化检索策略，实现知识库自治迭代，大幅降低人工调优成本；
标准化 MCP 资源输出，无缝对接 Prompt/Token/Skill/Agent/MaaS 全 AI 链路，作为所有大模型应用统一可信知识供给层；
支撑企业 AI 从 “无依据生成” 升级为 “有私有事实支撑的可信智能”，是全域 AI 体系不可或缺的底层知识支撑中台。
